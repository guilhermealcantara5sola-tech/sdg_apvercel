======================================================================
              COMO USAR O ROBÔ DE DISPAROS NO MACOS (MAC)
======================================================================

Como o macOS possui diretrizes de segurança rigorosas para arquivos
baixados da internet, siga os passos simples abaixo para rodar o robô:

----------------------------------------------------------------------
PASSO 1: Dar permissão de execução aos scripts (Apenas na primeira vez)
----------------------------------------------------------------------
1. Abra o aplicativo "Terminal" (você pode pesquisá-lo no Spotlight com Cmd+Espaço).
2. Digite o seguinte comando (digite um espaço depois dele):
   chmod +x 
3. Arraste o arquivo "iniciar_mac.command" de dentro desta pasta para
   a janela do Terminal (isso preencherá o caminho do arquivo automaticamente).
4. Pressione a tecla ENTER.
5. Repita o mesmo para o "compilar_mac.command" se desejar compilar depois:
   chmod +x [arraste o compilar_mac.command] e aperte ENTER.

Pronto! Agora o macOS sabe que estes arquivos são scripts seguros.

----------------------------------------------------------------------
PASSO 2: Executar o Robô
----------------------------------------------------------------------
1. Basta dar dois cliques no arquivo "iniciar_mac.command".
2. O terminal do Mac se abrirá e:
   a) Verificará se você tem o Python 3 instalado (caso não tenha, ele pedirá
      para você baixar em https://www.python.org/downloads/).
   b) Criará uma pasta chamada "venv" e instalará todas as dependências
      automaticamente (como Flask, Instagrapi, etc.).
   c) Iniciará o servidor do robô.
3. Copie a chave de pareamento (token) exibida no terminal do Mac.
4. Insira a chave na interface web do robô e pronto!

----------------------------------------------------------------------
PASSO 3 (Opcional): Compilar como Executável no Mac
----------------------------------------------------------------------
Se você preferir ter um arquivo executável único de clique duplo sem precisar 
rodar via terminal Python toda vez:
1. Dê dois cliques no arquivo "compilar_mac.command".
2. Ele fará todo o processo de build no seu Mac e gerará um executável 
   nativo do Mac chamado "server_mac".
